## Comandos git

- git init: Inicializa el repositorio local.
- git branch -M main: reemplaza la rama master por la rama main, volviendola la rama default
- git remote add origin "direcction del proyecto": conectar repositorio local con el repositorio remoto.
- git add . : registrar cambios
- git commit -m 'mensaje de commit': agregar descripcion a cambios registrados.
- git push -u origin main: subir cambios registrados al repositorio remoto

- git fetch
- git pull
- git merge
- git rebase
- git cherry pick
